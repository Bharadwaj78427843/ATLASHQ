## Sprint Design Constraints

> [!IMPORTANT]
> Every Sprint document must:
> 1. Trace every requirement back to a named platform and module in `docs/01-product/PRODUCT_MAP.md`
> 2. Never contradict the `ATLAS_CONSTITUTION.md`
> 3. Follow the mandatory document structure: Title · Version · Status · Purpose · Scope · Out of Scope · Dependencies · Owner · Reviewers · Revision History · Glossary · References · Engineering Review
